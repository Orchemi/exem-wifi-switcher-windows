# 설치 화면으로 처음 시험하기

회사 Wi-Fi에 연결하고, 기존 고정 IP 설정으로 정상적으로 연결되는 PC에서 시작하세요.
이 시험판은 Windows 11 x64용입니다. Windows 실기에서 설치 화면과 무선랜 전환을 아직 확인하지 않았습니다.

## 설치

1. `WifiProfileSwitcher-Setup-0.2.0-alpha.3.exe`를 더블클릭하고 Windows 관리자 승인을 허용하세요.
2. 감지된 Wi-Fi 이름, 고정 IP, 서브넷, 게이트웨이, DNS가 현재 회사 설정인지 확인하세요. 감지 실패 시 직접 입력할 수 있습니다.
3. **저장하고 시작**을 누른 뒤 변경 내용을 승인하세요. 설정 저장 후 자동 전환 시작을 시도합니다.
4. **자동 전환 → 켜짐**을 확인하세요. 백그라운드 감지가 정상인지 확인한 뒤 자동으로 활성화합니다. 확인에 약 1분이 걸릴 수 있습니다.
5. 완료 후 창을 닫으세요. 자동 전환은 백그라운드에서 계속 동작합니다.

다운로드한 EXE 하나에 필요한 파일이 들어 있습니다. 압축 해제, .NET 별도 설치, PowerShell 창이나 명령어 입력은 필요하지 않습니다.
내부적으로 Windows에 포함된 PowerShell을 사용하므로 회사 정책이 이를 막으면 관리자 승인이 필요합니다.

## 자동 감지가 멈추는 경우

| 화면 상황 | 확인할 내용 |
|---|---|
| DHCP 자동 할당 | 현재 주소를 고정 IP로 저장하지 않습니다. 회사에서 고정 IP 설정을 마친 PC인지 확인하세요. |
| 연결된 Wi-Fi 없음 | 회사 Wi-Fi에 먼저 연결한 뒤 다시 감지하세요. |
| 여러 Wi-Fi 연결 | 사용할 Wi-Fi 하나만 연결하세요. |
| DNS 자동 설정·복수 IP·사용자 지정 경로 | 이 시험판이 그대로 보존할 수 없는 구성입니다. 네트워크 관리자에게 확인하세요. |
| Wi-Fi 이름 조회 실패 | Windows 위치 권한과 회사 정책을 확인하세요. |
| 설치 중 설정 변경 | 연결과 값을 다시 확인하세요. 확인하지 않은 값으로 진행하지 않습니다. |
| 백그라운드 감지 실패 | 설치는 유지하지만 자동 전환을 켜지 않습니다. 서비스 계정 조회 제한을 관리자에게 확인하세요. |
| 실행·설치 차단 | 파일 출처와 [권한 안내](PERMISSIONS.md)를 확인하세요. 보안 제품이나 조직 정책을 끄지 마세요. |

SSID가 회사 소유인지 프로그램이 인증하는 것은 아닙니다. 사용자가 감지된 Wi-Fi가 회사 연결인지 확인해야 합니다.
다른 Wi-Fi에서 별도의 고정 IP가 필요한 PC는 기본 DHCP 전환을 켜지 마세요.

## 동작 확인

다음 항목은 실제 PC에서 확인해야 합니다. 네트워크가 끊겨도 직접 조작할 수 있는 환경에서 시험하세요.

- 회사 Wi-Fi에서 현재 고정 IP가 유지되는지 확인하세요.
- 외부 Wi-Fi로 바꾸면 IPv4와 DNS가 자동 설정으로 바뀌는지 확인하세요.
- 회사 Wi-Fi로 돌아오면 처음 저장한 고정 IP와 DNS가 복원되는지 확인하세요.
- 절전 복귀·재부팅 후에도 감지하는지 확인하세요.
- Windows 설정에서 결과를 확인하세요. 서비스가 실행 중이라는 사실만으로 전환 성공을 판단하지 마세요.

## 중지·복구·제거

같은 Setup.exe를 다시 열면 설치된 설정을 불러옵니다.

- **자동 전환 → 끄기**: 현재 IP는 유지하고 자동 변경을 중지합니다. 다음 부팅에도 자동 변경하지 않습니다.
- **더 보기 → DHCP로 복구**: 자동 전환을 끄고 IP·DNS를 자동 설정으로 바꿉니다. 회사 고정 IP 전용 망에서는 연결이 끊길 수 있습니다.
- **더 보기 → 최초 백업 복원**: 최초 변경 전 백업으로 복원합니다. 백업 당시 네트워크에 연결한 상태에서 사용하세요. 실제 전환 전에는 백업이 없을 수 있습니다.
- **더 보기 → 앱 제거**: 서비스·프로그램·설정·백업을 삭제합니다. 현재 IP는 바꾸지 않으므로 필요한 복구를 먼저 수행하세요.

기존 설치는 덮어쓰지 않습니다. 이전 시험판을 바꾸려면 필요한 복구를 마친 뒤 제거하고 다시 설치하세요.

성공·실패와 어느 단계에서 멈췄는지만 전달하세요.
감지 결과 화면, 설정 파일, IP·DNS·게이트웨이·MAC·사용자 경로를 이슈나 메신저에 첨부하지 마세요.
