회사 Wi-Fi는 고정 IP, 다른 Wi-Fi는 자동 IP를 사용합니다.

설정설치 전자동 전환꺼짐

자동 감지 실패. 회사 Wi-Fi와 IP를 직접 입력해 주세요.

흐름: 감지 실패 → 회사 Wi-Fi·고정 IP 입력 → 저장 → 자동 전환 켜기.
수동 저장은 Wi-Fi 이름 감지 없이 가능합니다. 자동 전환을 켤 때는 현재 회사 Wi-Fi를 읽을 수 있어야 합니다.
모든 주소와 Wi-Fi 이름은 문서용 예시입니다. 기존 설치 업데이트는 이 미리보기로 검증되지 않습니다.
