# 수동 설정 시험 안내

0.2.0-alpha.3는 Windows 실기 미검증 시험판입니다. Windows x64에서 Setup EXE를 실행하세요. 터미널 입력은 필요 없습니다.

1. Windows 관리자 승인 창에서 실행 파일을 확인하고 ‘예’를 누릅니다. 회사 정책으로 거부되면 관리자 승인이 필요합니다.
2. 자동 감지가 실패하면 Wi-Fi 어댑터를 선택하고 회사 Wi-Fi 이름, 고정 IP, 서브넷 마스크, 게이트웨이, DNS를 입력합니다. 회사에서 할당한 주소를 사용하세요. 미리보기의 주소는 사용하지 마세요.
3. ‘저장하고 시작’을 누르고 변경 내용을 승인합니다. 설정 저장 후 회사 Wi-Fi 감지를 확인하고 자동 전환을 시작합니다. IP가 변경되면서 연결이 잠시 끊길 수 있습니다.
4. ‘켜짐’을 확인합니다. 감지에 실패하면 설정은 보존되고 자동 전환은 꺼집니다. 연결·권한을 확인한 뒤 ‘저장하고 시작’으로 다시 시도하세요.
5. 회사 Wi-Fi와 다른 Wi-Fi를 오가며 고정 IP 및 자동 IP 전환을 확인합니다. 미확인 SSID에서는 기존 설정을 유지해야 합니다.

오류가 나면 ‘더 보기 → 오류 정보 복사’로 코드만 공유하세요. 입력값이 보이는 화면은 공유 전에 가려 주세요.

기존 설치의 설정 저장은 서비스 프로그램 자체를 업데이트하지 않습니다. 이전 시험판이 설치되어 있다면 필요한 복구를 먼저 수행하고 설정을 안전한 곳에 기록한 뒤, ‘더 보기 → 앱 제거’ 후 새 EXE로 설치하세요. 제거하면 설정과 최초 백업도 삭제됩니다. 현재 IP는 유지됩니다.

UI-PREVIEW.html은 버튼을 눌러 보는 HTML 미리보기입니다. Windows 실행 캡처가 아니며 실제 네트워크를 바꾸지 않습니다.
