# 안내 이미지 출처

- `windows-more-info.png`, `windows-run-anyway.png`: [ASUS의 Windows SmartScreen 안내](https://www.asus.com/support/faq/1053651/). Windows 경고의 버튼 위치를 보여 주는 예시이며 이미지의 앱 이름은 이 프로젝트와 다릅니다.
- `windows-uac.png`: [Microsoft의 관리자 승인 안내](https://learn.microsoft.com/en-us/windows/security/application-security/application-control/user-account-control/). 실제 앱 이름과 게시자 표시는 다릅니다.
- `setup-manual.png`, `setup-saved.png`, `setup-blocked.png`: Windows에서 실행한 설정 창. 캡처용 SSID와 문서용 IP를 사용합니다.
