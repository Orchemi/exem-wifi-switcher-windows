01 · 실행 전

전달받은 설치 파일을 확인하세요

이 가이드는 아래 이름의 Windows x64 시험판을 기준으로 합니다. HTML은 안내 파일이며 설치 파일은 별도로 필요합니다.

WifiProfileSwitcher-Setup-0.2.0-alpha.2.exe
  1. 만든 사람에게 직접 받았거나, 조직에서 승인한 전달 경로로 받은 파일인지 확인하세요.
  2. 파일 탐색기의 다운로드 폴더에 저장하세요. 압축을 풀거나 다른 프로그램을 설치할 필요는 없습니다.
  3. 회사 Wi-Fi에 연결하고 기존 고정 IP 설정으로 정상 연결되는 PC에서 시험하세요.

현재 공개된 이전 릴리즈 ZIP은 설치 방법이 다릅니다. 이 가이드의 EXE와 혼동하지 마세요.

선택: 명령어 없이 파일이 같은지 확인하기

아래에서 EXE를 선택하면 브라우저 안에서 SHA-256을 계산합니다. 파일을 업로드하지 않습니다. 일치는 전달받은 파일이 개발자가 만든 파일과 같다는 뜻이며, 안전성 인증이나 회사의 실행 승인을 대신하지 않습니다.

02 · 브라우저에서 파일을 저장하지 못할 때

Edge에서 ‘유지’를 찾으세요

“일반적으로 다운로드되지 않습니다”처럼 알려지지 않은 파일에 대한 평판 경고가 표시되고, 파일 출처와 실행 승인을 확인한 경우의 절차입니다. 경고가 없으면 다음 단계로 넘어가세요.

① 다운로드 목록 → ⋯ → 유지

Ctrl + J를 눌러 다운로드 목록을 여세요. 해당 파일의 ⋯ 메뉴에서 유지(Keep)를 선택합니다.

메뉴가 안 보이면 파일 항목 위에 마우스를 올려보세요.

② 더 보기 → 그래도 계속

추가 확인창에서 더 보기(Show more)를 펼친 뒤 그래도 계속(Keep anyway)을 선택합니다.

한국어 표현이 다른 경우 영문 이름과 함께 비교하세요. 다운로드가 끝나면 파일 탐색기에서 EXE를 찾습니다.

이 경우에는 진행하지 마세요.

“바이러스 발견”, “악성 파일”, “조직에서 차단”이라고 표시되거나 유지 메뉴가 없다면 관리자에게 확인하세요. SmartScreen·백신·회사 정책을 끄는 절차는 필요하지 않습니다.

03 · EXE를 더블클릭한 뒤

실행 경고와 관리자 승인은 다른 화면입니다

서명되지 않은 새 시험판이므로 Windows가 평판 경고를 표시할 수 있습니다. 파일 출처와 조직의 실행 승인을 확인한 경우에만 진행하세요.

① ‘Windows의 PC 보호’ → 추가 정보

처음에는 실행 버튼이 숨겨져 있습니다. 본문 아래의 추가 정보(More info) 링크를 누르세요.

닫기나 실행 안 함을 눌렀다면 파일 탐색기에서 같은 EXE를 다시 더블클릭할 수 있습니다.

② 파일 이름 확인 → 실행

앱 이름이 전달받은 WifiProfileSwitcher-Setup 파일인지 확인한 뒤 실행(Run anyway)을 누릅니다.

이 시험판은 서명되지 않아 ‘알 수 없는 게시자’가 나올 수 있습니다. 표시된 프로그램이 다르거나 실행 버튼이 없으면 진행하지 마세요.

③ 관리자 승인 → 왼쪽 ‘예’

다음으로 관리자 승인창이 나타납니다. 파란색 ‘아니오’를 누르면 이번 실행이 취소됩니다. 파일 이름을 확인한 뒤 왼쪽 예(Yes)를 누르세요.

맨 위의 실제 관리자 승인 화면 보기

다른 관리자 계정의 암호를 요구하면 회사 관리자에게 요청하세요. 승인 후 설치 화면이 나타날 때까지 잠시 기다리세요.

관리자 권한은 프로그램 설치와 IP·DNS 변경에 필요합니다. 승인만 했다고 즉시 IP를 바꾸지는 않습니다.

04 · 앱은 열리지만 회사 Wi-Fi를 읽지 못할 때

위치 권한 문제라고 단정할 수는 없습니다

0.2.0-alpha.2은 접근 거부, SSID 미확인, 조회 API 실패 등을 같은 안내로 표시합니다. 따라서 이 문구만으로 원인을 구별할 수 없습니다.

Windows에서 보이는데 이 앱에서만 안 보이면 앱 쪽 문제일 수도 있습니다.

이 앱은 주변 Wi-Fi를 검색하지 않고 현재 연결의 이름을 읽습니다. Microsoft가 SSID 조회용으로 안내하는 API를 사용하고 있어, 위치 권한을 켜는 것만으로 해결된다고 보장할 수 없습니다.

① 먼저 Windows의 현재 연결을 확인하세요

시작 → 설정 → 네트워크 및 인터넷 → Wi-Fi

회사 Wi-Fi에 실제로 연결되어 있는지 확인하세요. 유선 LAN만 연결되어 있거나, Wi-Fi가 꺼져 있거나, VPN 연결만 있는 상태에서는 회사 Wi-Fi 프로필을 가져올 수 없습니다.

② 위치 설정은 ‘확인’부터 하세요

시작 → 설정 → 개인 정보 및 보안 → 위치

위치 서비스와 앱 접근 허용 상태를 확인하세요. 회사에서 허용하고 필요한 경우에만 켠 뒤 앱의 다시 감지를 눌러보세요.

“조직에서 관리”라고 나오거나 토글이 잠겨 있으면 회사 관리자에게 문의하세요. EXE 앱은 앱별 허용 목록에 나타나지 않을 수 있으므로, 이름이 없다고 설치 실패로 판단하지 마세요.

Windows 위치 설정 열기Windows에서만 동작합니다. 안 열리면 위 메뉴로 이동하세요.

아래 항목만 적어 보내면 됩니다. 오류 화면을 캡처한다면 오류 문구 부분만 잘라 주세요. 회사 Wi-Fi 이름, IP·DNS·게이트웨이, MAC, 계정 이름은 가려 주세요.

05 · 감지에 성공하면

값을 다시 입력하지 않고 설치합니다

  1. 감지된 회사 Wi-Fi와 고정 IP·서브넷·게이트웨이·DNS가 이 PC의 기존 값인지 확인하세요.
  2. 확인 체크박스를 선택하고 이 설정으로 설치를 누르세요.
  3. 설치 완료 후 자동 전환 켜기를 누르세요. 백그라운드 확인에 약 1분이 걸릴 수 있습니다.
  4. 완료 후 창을 닫으세요. 회사 Wi-Fi에서는 저장한 설정, 다른 Wi-Fi에서는 DHCP를 사용합니다.

다른 Wi-Fi에서도 별도 고정 IP가 필요한 PC는 자동 전환을 켜지 마세요. 문제가 있으면 같은 EXE를 다시 열어 자동 전환을 끄거나 복구할 수 있습니다.

이 문서에는 실제 앱의 성공 화면 캡처가 없습니다. 공개 Windows 경고 화면과 코드상 절차를 정리한 안내이며, 현재 보고된 Wi-Fi 감지 실패가 해결되었다는 뜻은 아닙니다.
