# 저장 후 자동 시작

‘저장하고 시작’ 한 번의 승인으로 관찰 모드 저장 후 Wi-Fi 검증과 활성화를 이어 수행한다. 시작 실패 시 저장값은 보존하고 Pause를 시도한다. Pause까지 실패하면 꺼짐으로 단정하지 않는다. 입력값 수정 중에도 끄기는 가능하며 미저장 입력값을 보존한다.

검증: 새 흐름 타입이 없는 상태에서 테스트 컴파일 실패를 확인한 뒤 구현했다. Core 77개 테스트 통과. Setup 크로스 빌드 통과. HTML에서 승인 취소, 저장 후 시작, 중지 후 재시도를 확인했다. Windows CI에서 정상/시작 실패 캡처와 설치·서비스 검사를 수행한다. 실제 무선랜 전환은 실기 미검증이다.
