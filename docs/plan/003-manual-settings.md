# 수동 설정과 간결한 설정 창

Wi-Fi 이름 감지가 실패해도 물리 Wi-Fi 어댑터를 선택하고 회사 SSID, 고정 IPv4, 서브넷 마스크, 게이트웨이, DNS를 저장할 수 있게 한다. SSID 권한 실패와 IP 정보 조회를 분리한다. DHCP 주소는 고정 IP로 자동 채우지 않는다.

‘저장하고 시작’에서 변경 내용을 한 번 승인한다. 먼저 observe 모드로 저장한 뒤 자동 시작을 시도한다. 시작 전 현재 회사 SSID와 최신 서비스 관측 결과를 확인한다. SSID 미확인 시 설정을 보존하고 자동 전환은 보류한다. 시작 실패 시 Pause로 중지하며 중지까지 실패하면 상태 확인 필요를 표시한다. 정책을 우회하거나 SSID를 추측하지 않는다.

기본 화면은 입력란 여섯 개, 설정 상태, 자동 전환 상태, 저장하고 시작 버튼으로 구성한다. 복구·삭제·진단은 ‘더 보기’에 둔다. 앱 내부 확인은 ‘예/아니오’ 대신 ‘설치/저장/켜기/복구/제거’를 사용한다. Windows UAC는 변경하지 않는다.

복수 프로필은 간결한 편집기에서 편집하지 않으며 숨은 프로필을 삭제하지 않는다. 기존 설치의 어댑터 변경은 최초 백업과의 일관성을 위해 거부한다.

HTML 미리보기는 실제 Windows 실행 캡처가 아니다. UiSpec의 색상·문구·크기를 참고해 구성하며 네이티브 컨트롤 렌더링 차이가 있다. Windows CI의 `--capture-ui`는 예시 데이터만 사용하고 네트워크를 읽거나 변경하지 않는다.
