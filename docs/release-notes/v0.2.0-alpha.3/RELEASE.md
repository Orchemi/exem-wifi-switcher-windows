# v0.2.0-alpha.3

[Windows 설치 파일 다운로드](https://github.com/Orchemi/exem-wifi-switcher-windows/releases/download/v0.2.0-alpha.3/WifiProfileSwitcher-Setup-0.2.0-alpha.3.exe)

‘저장하고 시작’을 누르면 설정을 저장하고 Wi-Fi 감지를 확인한 뒤 자동 전환을 시작합니다. 별도로 ‘켜기’를 누를 필요가 없습니다.

- 감지 실패 시 설정은 보존하며 자동 전환을 시작하지 않습니다. 연결·권한을 확인한 뒤 같은 버튼으로 다시 시도할 수 있습니다.
- 실행 중에는 ‘끄기’를 표시합니다. 시작 실패 후 중지까지 실패하면 상태 확인 필요를 표시합니다.
- 현재 IP를 자동 복원하지 않습니다. 필요하면 ‘더 보기’의 복구 기능을 사용하세요.

Windows x64용입니다. 실제 Wi-Fi 전환·절전 복귀는 장비에서 확인이 필요합니다. 관리자 승인이 필요하며 조직 정책을 우회하지 않습니다.

기존 GUI 설치가 있다면 새 Setup EXE를 열어 저장하고 시작할 수 있습니다. 이 버전은 GUI 동작 변경이며 기존 서비스 프로그램은 자동 업데이트하지 않습니다.
